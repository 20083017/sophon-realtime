# Agent orchestration

Use `sophon-plan` and `.claude/workflows/sophon-workflow.md` for routing and approval. Roles are optional owners, not a required chain. One writer per file scope; read-only roles return evidence and children do not delegate.

Routine edits need relevant minimal validation without saved plan records. Planned implementation receives actual approval/version/phase/files/acceptance. Never use delegation to bypass approval. Ordinary errors receive targeted correction; the planner classifies material boundaries. Generic agent instructions add no separate panel, lifecycle or retry quota.
