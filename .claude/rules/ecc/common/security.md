# Security

Apply root `AGENTS.md` and the canonical workflow to the changed surface. Preserve authentication, authorization, rate limits and input validation. Check relevant injection/path/subprocess/network boundaries and error disclosure; do not require unrelated web controls for an offline script.

Never hardcode or commit passwords, API tokens, private keys, internal connection values or private audio/history. Use user-local configuration and existing credential mechanisms. Keep report excerpts bounded and redact sensitive data. Do not create fake credentials in examples.

If a concrete security issue is found, preserve evidence and return the consequence and smallest correction to the existing owner/planner. Correct within approved scope; confirmed material safety boundaries stop affected work. Do not invoke an undefined reviewer, silently expand into a whole-repository audit, rotate credentials or modify unrelated services without the needed authorization.
